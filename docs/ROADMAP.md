# Roadmap to Mainnet

A phased path from specification to a live, audited network.

## Phase 1 — Foundation (Q3–Q4 2026)
- Key engineering hires (ZK circuit engineer, Cosmos SDK engineer)
- ZK circuit prototype (Halo2 / Plonky3)
- Attribution engine v1 (see `attribution-engine/` for the reference implementation)
- Advisory board formation

## Phase 2 — Testnet (Q1–Q2 2027)
- Public testnet launch
- Pilot partnerships with data creators / model providers
- Compute node onboarding

## Phase 3 — Mainnet Beta (Q3–Q4 2027)
- Mainnet beta launch
- Independent security audit
- Recursive Nova-based accumulation scheme R&D (for proving overhead reduction)

## Phase 4 — Scale (2028)
- Mainnet v1 general availability
- Ecosystem grants program for third-party integrations

## Known Risks

| Risk | Mitigation |
|---|---|
| ZK proving overhead at scale | Phased rollout + Nova recursive accumulation R&D |
| Token classification / regulatory | Legal counsel engaged pre-TGE |
| Single-founder execution risk | Priority hires funded by grants/seed round |
| Two-sided marketplace adoption | Pilot partnerships secured before mainnet |
